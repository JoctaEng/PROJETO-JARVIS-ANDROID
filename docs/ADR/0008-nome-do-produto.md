# ADR 0008 — Nome do produto: Euno

**Status:** aceita (Fase 1) · **Data:** 2026-10-06 · **Revisável**

## Contexto
"JARVIS" é marca da Marvel/Disney (roteiro, seção 1). O usuário listou ~150 opções e pediu uma escolha profissional, separando **plataforma** (o app) de **personagens** (Joca, Luna, Astra...).

## Verificação feita (busca web, 06/10/2026)
| Candidato | Conflito encontrado |
|---|---|
| Soul / Soul Myself / SoulMe | **Soul App** (Soulgate, Xangai) — app social com companheiro de IA, em processo de IPO. O prefixo "Soul" também está saturado (SoulMate AI, iSoul, Souleasy, Soulkyn). |
| Second Me | **Second Me / Me.bot** (Mindverse) — "seu eu de IA". |
| Nomi | **Nomi AI** — companheiro de IA com mais de 1 milhão de usuários. |
| Aura, Lumi | Vários apps de companhia/IA com o mesmo nome. |
| Nexo | **Nexo** — plataforma de cripto conhecida. |
| myON / Myon | **myON** — plataforma de leitura escolar (Renaissance). |
| OtherMe | Próximo de **Otherhalf AI** (companheiro 3D). |
| **Euno** | Empresa B2B de metadados (Euno, EUA) e apps "Eunoia" de bem-estar. Nenhum app de companhia/assistente encontrado. |

## Decisão
**Euno — Seu segundo eu digital.** Vem de "Eu" + "one": curto, de raiz portuguesa e fácil de pronunciar. "Soul Myself" fica como filosofia do produto.

Só o nome visível mudou. O pacote interno (`com.joctaeng.jarvis`) continua o mesmo, para o APK atualizar sem perder dados.

## Antes de publicar
Busca web não substitui busca de marca: consultar o INPI (busca.inpi.gov.br) nas classes 9 e 42 e conferir as lojas de apps.
